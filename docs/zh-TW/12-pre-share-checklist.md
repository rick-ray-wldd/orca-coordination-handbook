# 第 12 章　分享前檢查

[English](../en/12-pre-share-checklist.md) | [繁體中文](../zh-TW/12-pre-share-checklist.md) | [Home](../../README.md)

如果你照這本手冊建了自己的版本，之後想分享給朋友或同事，請先做這一章的檢查。本手冊本身也是這樣做出來的。

## 12.1 原則

- **人工重寫匿名摘要，優先於「整份複製再取代」。** 取代很容易漏掉藏在設定、changelog、註解裡的真實名稱與 ID。
- **公開區與私人區分開。** 要分享的東西放 `public/`；來源對照、稽核紀錄、測試證據、黑名單放 `private/` 或收據資料夾，打包時用**白名單**只收 `public/` 裡列出的檔案。
- **黑名單本身是私人的。** 用來掃描的「真實名稱清單」絕對不能被打包。

## 12.2 要檢查的內容

| 類別 | 要找的東西 |
|---|---|
| 身份 | 真實姓名、暱稱、帳號、Email、電話、學號、員工編號 |
| 組織 | 學校、系所、實驗室、公司、社團名稱 |
| 關係 | 家人、同學、同事、合作者的名字與關係描述 |
| 專案 | 私人專案名稱、產品代號、課程代碼 |
| 路徑 | 含使用者名稱的絕對路徑（例如家目錄底下的路徑） |
| ID | 真實的 session、task、project、workspace、terminal、訊息、執行、雲端硬碟、聊天平台 ID |
| 網址 | 私人網址、內部網址、未公開的部署網址 |
| 原始資料 | 截圖、終端輸出、日誌、資料庫內容、設定檔、對話紀錄 |
| 秘密 | 金鑰、token、`.env`、憑證 |
| 習慣與環境 | 固定作息時刻、時區、所在地、機器型號、特定模型版本與訂閱方案 |

## 12.3 要檢查的位置

- 正文文字（Markdown、HTML、PDF 的可選取文字）
- **檔名與資料夾名**（包括 ZIP 裡的路徑）
- **HTML 註解與隱藏欄位**
- **PDF metadata**（Title、Author、Creator、Producer、Subject、Keywords）；列印時關掉頁首頁尾，否則可能印出本機檔案路徑
- 圖片（SVG 裡的文字、點陣圖的 EXIF、截圖裡看得到的字）
- 程式碼範例中的預設值與註解
- JSON 範例中的 changelog、updated_by、approved_by 這類欄位

## 12.4 建議的自動掃描

1. 在**私人區**建一份黑名單（每行一個正規表示式）：你的名字、帳號、學校、專案名、家目錄路徑、`@` 信箱網域，以及「看起來像真實 ID」的樣式，例如：
   - `[TSPW]-` 後面接 12 個以上十六進位字元
   - `term_`、`msg_`、`run_` 後面接十六進位字元
   - 標準 UUID 樣式
   - 常見金鑰前綴
2. 對公開區的**每個檔案內容、每個檔名、PDF 抽出的文字與 metadata** 跑一次。
3. 檢查 HTML 沒有載入任何外部資源（沒有外部圖片、字型、script 或 CDN；導向公開 repo／官方來源的超連結可保留，離線阅读不得依賴它們）。
4. 解壓 ZIP 到暫存資料夾，比對每個檔案的 SHA-256 與你凍結的清單一致，確認沒有多出來的檔案。
5. 把 PDF 每一頁渲染成圖片，至少親眼看幾頁，確認可讀、沒有意外內容。

## 12.5 最後一道人工檢查

- [ ] 全部例子都是虛構的（網站A、研究B 這種）
- [ ] 所有路徑都是 `HUB_ROOT`、`PROJECT_ROOT` 之類的佔位字
- [ ] 私人範例網址使用 `example.invalid`；公開 repo／官方來源導覽連結為刻意保留
- [ ] 所有 ID 都含 `EXAMPLE`
- [ ] 沒有任何截圖原件、日誌、對話
- [ ] 模型名稱都是佔位字或明確標示「依你的環境」
- [ ] 沒有說「下載後腳本就能用」，除非真的附了腳本並測過
- [ ] 黑名單、來源對照、稽核紀錄都不在 ZIP 裡
- [ ] ZIP 附 SHA256SUMS，解壓比對一致

完整的可複製清單：`templates/zh-TW/pre-share-checklist.md`。

## 公開 GitHub 額外檢查

檢查所有 Git commit（包含已刪除檔案）、作者／提交者／tag 信箱、release 附件與 CI 日誌。乾淨的新目錄不代表舊 Git 歷史沒有個資；請另建公開 repo。私人 denylist 不能加入版控。通用掃描不等於能識別所有個資。
