# Before sharing

## Structure
- [ ] Public material separate from private source indexes, receipts and denylist.
- [ ] Explicit packaging allowlist; no complete private directory copy.
- [ ] Anonymous examples rewritten rather than superficial substitutions.

## Content
- [ ] No names, private handles/email/phone/IDs, organizations or identifying relationships.
- [ ] No private project names, codes, absolute user home paths or internal URLs.
- [ ] Placeholder IDs visibly use EXAMPLE; sample links use example.invalid.
- [ ] Public repository/reference navigation links are intentional.
- [ ] No original screenshots, logs, settings, database, conversations or credentials.
- [ ] No identifying routine/location/device/subscription details.
- [ ] Environment-dependent models are labeled; included tools are accurately described.

## Hidden locations
- [ ] Filenames, directories, archive paths, HTML comments/meta/hidden elements.
- [ ] No external offline assets, fonts, CDN or tracking.
- [ ] PDF metadata and print headers/footers; no local paths.
- [ ] SVG text, image EXIF and screenshot pixels.
- [ ] JSON changelog/updated_by/approved_by.
- [ ] All Git commits, removed files, author/committer/tag identities and release assets.

## Verification
- [ ] Private personal denylist scanned paths, text and PDF extraction/metadata.
- [ ] Generic secret, UUID and real-looking runtime-ID patterns checked.
- [ ] All relative links and locale counterparts resolve.
- [ ] ZIP exact file set and hashes match frozen manifest.
- [ ] PDF pages rendered and visually reviewed.
- [ ] Fresh anonymous clone and quickstart tested.
- [ ] SHA256SUMS included.
- [ ] Review scope and limitations recorded honestly; independent review if available.
- [ ] User authorized this specific public release.
