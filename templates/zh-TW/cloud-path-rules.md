# 雲端硬碟路徑規則

示範用規則：讓每個平台（Orca、聊天、電話 bot）都用同一種方式指向同一個雲端根資料夾裡的檔案。所有 EXAMPLE 值都是虛構的。填好的版本請私下保存。

## 地址只有一種寫法

```text
<ROOT-EXAMPLE>/<組>/<專案>/<類型>/<YYYY-MM-DD_主題_說明_v版本.副檔名>
```

例：`HQ-EXAMPLE/2-專案/website-a/媒體/2099-01-01_發布展示_手機版_v1.mp4`

訊息、文件和工單一律寫這個地址，不寫某台電腦的路徑。組的編號和聊天頻道的分組相同。

## 組

| 組 | 放什麼 | 聊天頻道 |
|---|---|---|
| `00-先讀` | 這份規則、專案對照表 | 無 |
| `1-總入口` | 跨專案的文件 | 1- |
| `2-專案` | `website-a`、`research-b` | 2- |
| `3-合作` | `partner-x` | 3- |
| `4-學業` | `課程`、`申請` | 4- |
| `5-生活` | `財務`、`保險`（只放不含機密的） | 5- |
| `8-加密備份` | 只放加密檔 | 無 |
| `9-封存` | 超過 RETENTION-EXAMPLE 天的媒體與結案資料，依組／專案分 | 無 |

新專案先加進專案對照表，再建資料夾。客戶資料夾用客戶公開的名稱，不用內部代碼。

## 類型只有四種（第一次用到再建）

| 類型 | 放什麼 |
|---|---|
| `交付` | 給別人或已定稿的成品 |
| `媒體` | 影片、圖片、3D、素材 |
| `文件` | 研究、規格、筆記、簡報 |
| `收據` | 驗證證據、截圖、QA 報告 |

## 檔名

- `YYYY-MM-DD_主題_說明_v版本.副檔名`；日期用系統時鐘取，不手打。
- 改版就加新的版本號，不覆蓋。
- 不放內部案件代碼、工具名稱、金額或個資：分享時檔名看得到。

## 各平台怎麼找到檔案

| 平台 | 怎麼找 | 能做什麼 |
|---|---|---|
| Orca | 桌面同步用戶端的資料夾＋地址（串流模式） | 讀、寫 |
| 電話／聊天 bot | 它的雲端硬碟連線，用名稱搜尋 | 只能讀；要存檔交給 Orca |
| 聊天（Slack） | 貼雲端連結（顯示預覽）；PDF 也可以傳到專案頻道 | 看、貼連結；正本仍放雲端 |

## 什麼能放在哪

| 層級 | 內容 | 規則 |
|---|---|---|
| 直接放 | 交付成品、媒體、研究、公開資料、規則文件 | 專案資料夾 |
| 加密才放 | 專案機密資料、客戶資料、個資、成績、證件、財務、保險、報價和成本、沒有遠端備份的 repo | 只放 `8-加密備份`，用擁有者的公鑰加密；agent 永遠不持有私鑰 |
| 永遠不放 | 密碼、金鑰、token、`.env`、私鑰 | 加密也不放 |
| 不搬 | 開發中的 repo 資料夾、`.git`、相依套件資料夾、資料庫 | 同步會弄壞它們；程式碼靠 Git，雲端只放加密打包檔 |

為什麼這麼嚴：bot 平台的雲端硬碟連線通常涵蓋整個帳號、所有 bot 共用，不能限定在某個資料夾。

## 分享與搬檔

- 預設不分享給任何人。分享或公開連結是對外動作 → 決策卡。
- 搬到雲端：複製 → 核對雜湊 → 確認雲端有了 → 才刪本機。只有媒體和結案資料會刪本機。
- 必須維持公開的既有分享資料夾留在原處；列在這裡：EXISTING-SHARED-EXAMPLE。
