# 決策紀錄（範本）

> 任務需要 User 決定時（狀態 `waiting_user`）使用。一次只問一個決定；選項要能直接選。

```
# 決策 <D-EXAMPLE-00>：<一句話問題>

- 任務：<T-EXAMPLE0000>
- 提出者：<督導總控>
- 提出時間：<YYYY-MM-DD HH:MM>
- 需要在何時前決定：<日期；說明是 target 還是 confirmed_deadline>
- 不決定的影響：<例如：writer 暫停，交付延後>

## 背景（三句以內）
<...>

## 選項
| 選項 | 內容 | 好處 | 代價／風險 | 是否涉及對外動作或新增支出 |
|---|---|---|---|---|
| 1 | <...> | <...> | <...> | 否 |
| 2 | <...> | <...> | <...> | 是：<需要你另外授權什麼> |

## 建議
<選項 N，理由一句>

## User 決定（由 User 確認後填寫）
- 決定：<選項 N／其他：...>
- 確認方式與時間：<在哪個對話、何時>
- 附帶授權：<無／授權「...」這一次>
```

## 注意

- 「附帶授權」只涵蓋寫明的那一次動作。
- 決定記錄後，任務回到 `working`，next 寫下一步。
- 決定若改變了路由或範圍，同步更新派工訊息與路由表。
