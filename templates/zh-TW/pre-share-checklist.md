# 分享前去識別化清單（範本）

> 把自己的工作流程文件分享給別人之前，逐項打勾。黑名單與掃描結果放在私人區，不要一起分享。

## A. 結構

- [ ] 要分享的檔案都在 `public/`；來源對照、稽核紀錄、測試證據、黑名單在 `private/` 或收據資料夾
- [ ] 打包用**白名單**（明確列出檔案），不是打包整個資料夾
- [ ] 公開檔案是人工重寫的匿名摘要，不是整份複製再取代

## B. 內容（每個公開檔案）

- [ ] 沒有真實姓名、暱稱、帳號、Email、電話、學號／員工編號
- [ ] 沒有學校、系所、實驗室、公司、社團名稱
- [ ] 沒有家人、同學、同事、合作者與關係描述
- [ ] 沒有私人專案名稱、產品代號、課程代碼
- [ ] 沒有含使用者名稱的絕對路徑；一律 `HUB_ROOT`、`PROJECT_ROOT`
- [ ] 沒有真實 session／task／project／workspace／terminal／訊息／執行／雲端硬碟／聊天平台 ID；一律含 `EXAMPLE`
- [ ] 沒有私人或內部網址；範例用 `example.invalid`，公開 repo／官方來源導覽連結可保留
- [ ] 沒有截圖原件、終端輸出、日誌、資料庫內容、設定檔原件、對話
- [ ] 沒有金鑰、token、`.env`、憑證
- [ ] 沒有可推斷身份的作息時刻、時區、所在地、機器型號、訂閱方案
- [ ] 模型名稱是佔位字或標明「依你的環境」
- [ ] 沒有宣稱附了可執行腳本（除非真的附了並測過）

## C. 隱藏位置

- [ ] 檔名與資料夾名
- [ ] ZIP 內部路徑
- [ ] HTML 註解、`<meta>`、隱藏元素
- [ ] HTML 沒有外部資源（無 CDN、無外部字型、無外部圖片、無追蹤）
- [ ] PDF metadata：Title／Author／Creator／Producer／Subject／Keywords
- [ ] PDF 沒有頁首頁尾印出本機路徑
- [ ] 圖片：SVG 文字、點陣圖 EXIF、截圖中可見文字
- [ ] JSON 範例的 changelog、updated_by、approved_by

## D. 自動掃描（結果存私人區）

- [ ] 黑名單正規表示式掃過：檔案內容、檔名、PDF 文字、PDF metadata
- [ ] 真實 ID 樣式掃過（UUID、`term_`／`msg_`／`run_` ＋十六進位、`T-`／`S-`／`P-` ＋長十六進位）
- [ ] 外部資源掃過（图片、字型、script、CDN；公開導覽超連結可保留）
- [ ] 相對連結全部可解析
- [ ] ZIP 解壓後每個檔案 SHA-256 與凍結清單一致，沒有多餘檔案
- [ ] PDF 每頁渲染成圖，親眼看過至少數頁

## E. 最後

- [ ] 附 `SHA256SUMS`
- [ ] 由另一個人（或另一個代理，只讀）獨立再檢查一次
- [ ] 分享這個動作本身由 User 決定

- [ ] 所有 Git 歷史與作者／提交者／tag 身份、刪除檔案、release 附件已檢查
- [ ] 未登入狀態可 clone，並可依 quickstart 複製模板
